## 3. 遗留问题(已全部拍板解决,2026-08-20)

**3.1 dev 提交缺陷 → 已拍板:保留权限**
产品确认 dev 可提缺陷合理。权限保留,错误文案改为按权限点提示("当前角色无提交缺陷权限(bug:create)")。

**3.2 sys_admin 业务权限 → 已裁剪并根治**
sys_admin 权限表裁剪为:15 个查看类菜单 + `system:manage` + `requirement:delete` + `project:delete`;工单分诊移交新角色 **support(售后工程师)**(其他角色可兼任)。同时发现并移除 `RoleChecker`/`RoleService.myPermissions` 中 4 处 sys_admin 全量放行短路(此前权限表配置对 admin 完全无效的根因);治理看板显式放行 admin(观察类)。复测:admin 业务待办=0、建需求/任务/缺陷均 403、系统职能(用户/配置/角色/审计/全项目可见)全部正常、pm 业务不受影响。

**3.3 套件可重复性缺陷(已修)**
suite.sh 前置项目的 `$SFX` 写在单引号 printf 内不展开,projectCode 亦硬编码,二次执行撞唯一约束导致前置崩塌。已改为 `%s` 传参,复跑通过,可重复性承诺兑现。

## 4. 结论

核心安全(认证/权限/隔离)、核心流程(四大状态机+职责分离)、外部工单通道(匿名提交/防滥用/强制人工分诊)、待办明细契约与前端产物在本轮 98 用例全量测试下无缺陷。质量门禁的档位判定表与字数/数值边界全部按设计生效。**当前版本可作为基线提交**。
